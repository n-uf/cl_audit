The row under the title bar, redrawn three ways in Std, Black and Silver. Every control in a row shares one height and one centre line: a held-down key no longer drops a pixel. Its darker face and lit strip say it's on, and the edge under a key is drawn as a shadow, so it can't push the key off line. "Updated" sits in a fixed-width display, so "Updating…" and "1 h 12 min ago" take the same space. Emails is new here: an LED key, green while emails are shown.

Recommendation: A. It matches the home site's fascia (one recessed strip of keys between the name and the page keys), keeps everything on one 26 pt line, and folds cleanly into a second row when the window is narrow. B reads more "hi-fi" but is taller, and C puts most weight on information you rarely need to read.

AFascia with one key strip

Like the home site: the name, then one recessed strip holding the profile keys, the Emails key and the Updated display with its refresh key, then the page keys. Trade-off: one long strip; with many profiles it gets wide (it wraps to its own row first).
