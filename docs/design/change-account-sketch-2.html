Changing a profile's account · round 2

B is out. Round 1 was here. The look changes, and so does how the switch works.

The look: nothing that profile settings don't already have.
  • Rows with the label on the left and the address in plain text, with its light.
  • A pop-up drawn like Folder's.
  • Keys with a light.
  • One short grey line under a row saying what it means.
No display windows full of addresses and no boxed messages. A problem shows as its own row only while it lasts, like today's "Wrong account" row. The only display left is the plan ("MAX"), as on the dashboard card.
How the switch works now:
  • Started in cl_audit: you type the new address and sign in with Claude Code's own screen. cl_audit then links the profile by itself, so there's no second question.
  • Done outside cl_audit, like today's Terminal sign-in: cl_audit notices at once (no Refresh now) and asks once: Use this account or Log in again.
  • The Claude window: cl_audit knows only the account id the Claude app saves, never its address. So it says "another account" when the window doesn't match, and checks the standard window too.
  • One profile per account still holds, checked by account id.

Main is linked to ann@example.com, and Claude Code and the Claude window are both signed in to it. This is how a profile looks almost all the time: one address, one light, nothing else.

Recommended: E. It's today's card with the Folder pop-up's pattern applied to Login, and the Wrong account row you already know gains one key. Nothing moves, so the three columns stay as they are. Pick D if you want the account to read as the profile's identity, right under its name.

Open points

  • Which addresses the pop-up lists: this profile's account, the other profiles' accounts (marked, can't be picked) and Claude Code folders on this Mac that no profile uses (like ~/.claude-newacct). Picking one only fills in the sign-in; cl_audit never copies a sign-in between folders.
  • The old account afterwards: the last moment offers "Add as a profile…", so its limits stay watched. Keep or drop it?
  • Numbers while signed in elsewhere: hidden until you choose, as the seat design says. With the instant re-read, that's only until you click.
  • The window's earlier Code sessions stay under the old account. The last moment links to the claude-transplant how-to; nothing in cl_audit moves them.
