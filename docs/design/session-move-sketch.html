One profile, two of your accounts

A week in the life. The profile Claude Main works on ultra-1. When ultra-1's week is full, Main switches to ultra-2, and the Claude window opens with exactly the same sessions and sidebar. When ultra-1 is back, it switches back. Made-up data, Std face, nothing built.

The profile staysName, Dock icon, folder, projects, settings, MCP servers, CLAUDE.md: all unchanged. Only the account it works on changes.
The sessions followThe Code sidebar's sessions, sections, groups, pins and scheduled tasks move to the account you switch to, then back when you switch back.
It's not a settingSwitching is something you do when a limit is full, from the dashboard, an alert or a menu. Settings only list the profile's accounts and add one.

Found automatically, added on one click. cl_audit finds the accounts by itself, but adds one only when you pick it: old or team accounts the window once used stay out.
  • Every limit, with bars, for each account: the ones its plan has (Ultra: week and Fable; Max: 5-hour, week and Fable; Pro: 5-hour and week), plus usage credits when it spends them. The standby account's limits update like the one in use.
  • signed in: a Claude Code folder already holds its sign-in, so its limits show at once.
  • needs sign-in: Anthropic gives an account's limits only to a signed-in Claude Code, so a found account without a sign-in shows no numbers. One sign-in in Terminal and the browser, address filled in, fixes that for good: the sign-in is kept and renews by itself.
  • An account belongs to one profile: other profiles' accounts are dimmed.

What this needs you to decide
  1. A profile with two accounts. Today a profile has exactly one. This makes it “one or more, one at a time”, added in the profile's settings; New profile still starts with one. An account still belongs to one profile only.
  2. Sessions follow the account: on by default, as sketched, or asked each time on the switch page.
  3. Switching back: offered when the first account is back, as sketched, or never automatically.

To check before building: whether the window and Claude Code can each keep both sign-ins, so a switch needs no browser step.
