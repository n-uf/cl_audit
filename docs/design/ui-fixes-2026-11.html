cl_audit UI fixes, round 4

This round is drawn with cl-audit.n-uf.com's own stylesheet and the app's card and account-box markup, so the boxes, keys, displays and bars match the app. Only the changes are new. The samples: profile Main; ann@example.com is the account in use; ben@, cleo@ and dan@ are its other accounts.

Your notes, all in:
  • "Sign in" and "sign out" everywhere.
  • Sign in… is a reddish key, built like cl-quick's Download key.
  • The account in use keeps IN USE, which turns red when it isn't signed in.
  • The card's account line drops "· in use": the address with its lit lamp says it.
  • Red uses the selected row's look: bar outside, band edge to edge.
  • Boxes come in two shades only.
  • No text is cut off.
  • The unexplained ⋯ on standby rows is gone.
  • The half-done-switch note moves inside the selected account's display.
  • The signed-in card keeps Show window and Terminal.
  • Cards are drawn at the app's width (its 340 pt column), not stretched.
  • Menus are closed: click a key, ⋯ or an address to open one.
  • The Show emails switch (top right) blurs every address on every surface, as Settings does.
  • The card's SWITCH ACCOUNT is cl-quick's orange, in the keys row under the full display (Terminal into ⋯ meanwhile). The lit mint key stays in Settings ▸ Accounts.
  • The last refresh (“1 min ago”) moves into the plan badge on every card; the keys row holds keys only.

The badge's refresh time: every form, one width

The badge has a fixed width, set by the longest plan name and the longest time, so it never moves as the minutes tick, and every card's badge is the same size. It keeps its second line even before the first reading ("reading…"), so its height never changes either. Today the card's time grows without end ("23 h 59 min ago", "123 h 4 min ago"). 3–5 · Settings ▸ Main ▸ Claude Code ▸ Accounts

Each account is either in use (the one Main works on, the Claude app's) or standby. The markers show where it is signed in:

  • Claude app, which includes its Code tab, since that always shares the app's sign-in.
  • Claude Code in Terminal, the sign-in on Main's folder. Usage is read only through this one.

A profile has one Claude Code folder, shared by all its accounts, so only the account signed in to it is read. A standby account shows no numbers: one row, its details in full on a second line. The one exception is the split (C), where Claude Code in Terminal is signed in to a standby account on that same folder. Two shades only: the box in focus is dark (the account in use, or the selected standby while you pick one), and every other box is the unlit shade.
