2 · The Download on a computer that isn't a Mac

The page asks the browser which system it runs on. On a Mac nothing changes. On Windows, Linux, Android or an iPhone (an iPad, which says it is a Mac, is told apart by its touch screen) every Download key turns into an unlit key that can't be pressed, reading MAC ONLY. The menu bar shows "Mac only" as plain text. The demo, Install steps, GitHub and the build commands stay. Apple silicon versus Intel can only be told in Chrome and Edge, so an Intel Mac is flagged only there.

Unlit key, the reason in the display (built)

The hero's release display shows the reason instead, in amber: THIS COMPUTER ISN'T A MAC · cl_audit runs on macOS 13+, Apple silicon. No extra line; the message sits where the eye already goes. The release line itself is no longer shown on these systems.

3 · The little Dock on the Overview display (built)

After OVERVIEW: three pairs, each the Claude window as a display pictogram (a chat bubble in a rounded-square frame, lit orange lines) and its usage as two rings bare on the glass (5-hour outside, week inside, each in its level colour: green, amber from 50, red from 80). The Dock starts with one pair, the other two launch into it, growing from its centre; then every usage drifts on its own clock with eased changes, a 5-hour window resetting after it fills. When a usage first turns red (80 %) and when it reaches 100 %, an alert is typed in at the right end of the display for 3 s, worded to fit the free space; then it shrinks to a warning sign with the profile's name under it while that profile stays red.
