Also noticed (not drawn)

  • FAQ (data/faq.ts, “several accounts” answer) still says a profile can have a separate window next to the standard one and that only one profile can use the standard window: in 26.10.2 the profile using ~/.claude opens the usual Claude app, every other its own window, and it isn't a choice.
  • Icon card (i) texts (Colour, Frame, Claude open dot), Profile ▸ Icon label and Colour (i): the app has new wording (which colour each Colour row sets, frame = a ring to spot it quickly).
  • General ▸ Dock: the switch label is “Keep the cl_audit icons together”; the app says “Keep the Dock in order” (drawn in 10).
  • Now in the demo has two states; the app also shows STOPPED · IN THE DOCK / NOT IN THE DOCK / HIDDEN, MISSING · REINSTALL and RESTARTING THE DOCK….
  • Show Desktop windows (components/DesktopApps.astro) label a profile's window folder “Data folder”; the app no longer shows that name anywhere.
  • Name and Icon label: the app saves them on Return or when you click elsewhere (Esc puts them back); the demo saves as you type.
  • Face: the app's Face lives in General settings; the site keeps its Face keys in the title bar too (the sketch's Face card drives the same face).
