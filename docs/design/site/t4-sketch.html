cl_audit site · T4 front panel · whole-site sketch

Every control on the site as a part of one hi-fi front panel, from sketch T4. Window = brushed dark chassis; sections = raised modules with a printed label and engraved rule; every button, page switch and tab = a small aluminium key with an LED hole; lit orange LED = current page / chosen tab / the one prominent Download; display windows (cyan glass, glowing monospace) show the current page, the version line, the step numbers, switch states and the LOGIN · SECURITY badge. Keys press down a pixel; the current page stays latched down. The Mac menu bar and Dock stay as they are (they're the Mac, not the app).

1 · Overview, top of the page (1440 px)

Top strip: brand with a printed sub-label, a display window naming the page, and a PAGE key strip (the current page latched, LED lit). The hero: two profile modules and the intro module; its actions are the T4 plate. The version line becomes a display window. Menu bar Download is quiet (plain text) while the hero's Download key is in view: only one lit Download LED on screen.

cl_audit for Mac

Every Claude profile, side by side on your Mac.

A profile is one Claude setup: its Claude Code folder and sign-in, its Claude window and its Dock icon. cl_audit shows each profile's usage limits live in the Dock and on a dashboard, with figures read directly from Anthropic.

2 · Login section

One module. Badge = the V4 two-part readout (LOGIN dim, SECURITY lit). The five tabs are a row of keys; the chosen one latches down with its LED lit (no green, no icons). The explanation sits in a recessed readout under the keys that keeps the height of the longest explanation.

How cl_audit handles the Claude login

Details ›
The password is never seen

Sign-in happens in Claude's own screens: Claude Code's sign-in in Terminal (claude auth login) and the Claude app's sign-in window. cl_audit only opens them, so whatever is typed goes straight to Anthropic.

3 · Install, top of the page

Leads with the download: a DOWNLOAD plate with the one lit key and the release in a display window, then the three numbered steps (numbers in small display windows), ending with the Privacy & Security ▸ Open Anyway step drawn as macOS shows it. Requirements on the right; building from source comes after, in its own module.
