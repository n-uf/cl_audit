cl_audit · a name or label changed but not saved

Settings ▸ a profile ▸ Profile card, as built on branch name-field: a thin hairline under the field and a line of text under it, like a validation message. No dot by the label.

Try it: type in Name or Icon label, then press Return, Esc, or click elsewhere. Typing Work on Main (or Main on Work) shows the can't-save state. Switch tabs mid-edit: the text is saved to the profile it was typed for.

States

  • Typed, not saved: amber hairline; Return saves · Esc undoes under the field. The caps are clickable: Return saves, Esc puts the saved text back (the field keeps the focus). The label stays level with the typed text.
  • Can't be saved: red hairline; the reason under the field (Another profile is called “Work”); the top display says Not saved · see below.
  • Saved: back to the normal engraved line; the top display says Saved · Dock icon renamed for a few seconds.
  • Esc: the saved text comes back; no message.
